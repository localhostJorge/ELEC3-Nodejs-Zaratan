### N1 – Setup and Package Management
[Open N1 Folder](set1/n1-setup/)

Configured a Node.js project using npm, installed regular and development dependencies, and created a start script.

**Run the program:**
```bash
cd set1/n1-setup
npm install
npm start
```

### N2 – Modular Calculator
[Open N2 Folder](set1/n2-calculator/)

Created a command-line calculator using custom modules for mathematical operations and result formatting. Used the built-in OS module to display system information.

**Run the program:**
```bash
cd set1/n2-calculator
node index.js add 10 5
```

Available operations: `add`, `subtract`, `multiply`, `divide`, and `average`.

### N3 – File Manager
[Open N3 Folder](set1/n3-file-manager/)

Developed a menu-driven file manager using Node.js built-in `fs` and `path` modules. It supports creating, reading, updating, deleting, and listing text files, with error handling for missing files.

**Run the program:**
```bash
cd set1/n3-file-manager
node index.js
```
